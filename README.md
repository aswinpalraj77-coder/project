## 📌 Executive Summary & Prototype Brief

The **KSP AI Crime Intelligence Platform** is a next-generation police tech solution engineered to bridge citizens, police officers, and administrators under a single unified ecosystem. Powered by artificial intelligence, this platform helps officers predict crime hotspots, summarize complex case histories, map criminal networks, and automate officer briefings, while empowering citizens with instant e-FIR filing, emergency SOS, and cybercrime reporting.

---

## ✨ Key Features & Portals

### 1. 👮 Officer Portal (`/officer`)
- **AI Crime Assistant & Natural Language Search**: Search past FIRs, modus operandi, and crime histories using plain English/Kannada queries.
- **AI Case Summarizer**: Automatically generates multi-page case synopses, timeline analysis, and missing evidence alerts.
- **Predictive Crime Hotspot Map**: Interactive geospatial visualization powered by Leaflet to highlight crime-prone zones and plan optimized patrol routes.
- **Criminal Network Link Graph**: Visualize relationships, co-accused ties, and gang affiliations.
- **Officer AI Copilot**: Generate shift handovers, daily crime briefings, and investigation checklists on-demand.

### 2. 🏛️ Citizen Portal (`/citizen`)
- **Digital e-FIR & Complaint Filing**: File e-FIRs easily with AI guidance and document upload.
- **Live Case Tracking**: Real-time status tracker for submitted complaints with SMS/notification integration mockups.
- **Emergency SOS Dispatch**: One-tap panic trigger transmitting live GPS coordinates to nearest patrol units.
- **Cybercrime & Helpline Hub**: Instant reporting for financial fraud, harassment, and phishing, backed by an interactive AI Awareness Chatbot.

### 3. ⚙️ Administrator Portal (`/admin`)
- **Role & Access Control (RBAC)**: Manage police stations, officer ranks, and citizen access levels.
- **AI Model & Audit Control**: Monitor AI accuracy metrics, token usage, hallucination guardrails, and system logs.
- **System Health & Department Analytics**: Real-time audit trail and system performance dashboard.

## 💻 Local Setup & Installation

Follow these steps to run the platform locally on your machine:

```bash
# 1. Clone the repository
git clone https://github.com/aswinpalraj77-coder/project.git

# 2. Navigate to the project folder
cd project

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

Open `http://localhost:5173` in your browser to view the platform.
